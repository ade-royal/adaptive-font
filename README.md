# Adaptive Font

An experimental font system that generates varying levels of typographic messiness and adapts the font based on typing behavior.

## Goals

- Learn programmatic font generation
- Experiment with font manipulation
- Generate different levels of typographic variation
- Track typing behavior
- Develop a system that dynamically changes typography based on user input
- Explore the relationship between typing behavior and visual presentation

## Tech Stack

- Python
- FontTools
- Pillow
- SVG
- PySide6
